# Journey: learning alongside the unlocks

The game hands you the language piece by piece: first a `while`, then `plant`, `for`, `till`…
This track follows **that order**. Each page covers one milestone and only uses what the game
has unlocked up to that point, so you can read it next to the game without spoilers for
commands you do not have yet.

Every page has the same shape: **what the game unlocked**, **the idea**, **the code**, **the
most common mistake** and **an exercise**.

| # | Milestone | Unlocks / uses |
|---|---|---|
| 01 | [Harvest and repeat](01-colher-e-repetir.md) | `while`, `if`, `can_harvest`, `harvest`, `move`, `plant` |
| 02 | [`for` and the grid](02-for-e-a-grade.md) | `for`, `range`, `get_world_size` |
| 03 | [Soil and carrots](03-solo-e-cenoura.md) | `till`, `Entities.Carrot`, growth time |
| 04 | [Mixing plants](04-misturando-plantas.md) | 3-tile pattern, one phase to prepare and one to harvest |

## How to read the confidence marks

- ✅ **Tested**: someone ran it in the game and saw the result.
- 📖 **From the docs**: it is in the game's own text (public domain, CC0) but we did not verify it.
- ⏳ **Hypothesis**: looks right, **not measured yet**. Do not treat it as fact.

If you find a mistake, [open an issue](https://github.com/LucasCerattoRS/the-farmer-was-replaced-lab/issues/new?template=journey-feedback.md).
A plausible but wrong explanation is worse than "we do not know yet".
