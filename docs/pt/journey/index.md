# Jornada: aprendendo junto com os desbloqueios

O jogo libera a linguagem aos poucos: primeiro um `while`, depois `plant`, `for`, `till`… Esta
trilha acompanha **essa ordem**. Cada página cobre um marco e só usa o que o jogo já liberou
até ali, então dá para seguir lado a lado com o jogo, sem spoiler de comandos que você ainda
não tem.

Cada página tem a mesma forma: **o que o jogo liberou**, **a ideia**, **o código**, **o erro
mais comum** e **um exercício**.

## Como ler as marcas de confiança

- ✅ **Testado**: alguém rodou no jogo e viu o resultado.
- 📖 **Da documentação**: está no texto oficial do jogo (domínio público, CC0), mas não foi
  conferido por nós.
- ⏳ **Hipótese**: parece certo, **ainda não medido**. Não trate como fato.

Se você achar um erro, abra uma issue no repositório. Explicação plausível e errada é pior do
que "ainda não sabemos".

!!! note "Escrito por quem está aprendendo"
    Esta trilha nasce de uma jornada real, num save novo, com os erros que apareceram de
    verdade. Os marcos mais adiantados do jogo ainda não têm página aqui.
